## About

Each exercise is self-contained, making it easy to run, inspect, and modify individual examples.

## Features

- Array manipulation examples
- Common JavaScript algorithms
- ES6 syntax practice
- Small runnable Node.js scripts

## Tech Stack

- JavaScript
- Node.js

## Architecture

The repository uses a simple folder-per-topic approach. Each folder contains independent scripts with no shared runtime or build system.

## Project Structure

```text
JavaScript/
|- ArrayReduceTransformation/
|  `- run.js
|- FisherYates/

`- ReadMe.md
```

## Getting Started

1. Install Node.js.
2. Clone the repository.
3. Run an example from its folder:

```bash
node ArrayReduceTransformation/run.js
```

## Configuration

No configuration or environment variables are required.

## Security

Do not commit credentials, API keys, or other secrets. This repository does not require secrets to run its examples.

## How to Contribute?

1. Create a branch for your change.
2. Add or update an isolated exercise.
3. Run the affected script with Node.js.
4. Open a pull request with a clear description.
